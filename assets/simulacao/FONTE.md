# Ícones da simulação

Ilustrações vistas de cima (carros, ambulância) e de lado (pessoas) usadas no player do cruzamento da interface
(`src/operador/cruzamento.py`). Fornecidas pela autora do projeto (pasta `betterway-icones`); o fundo branco foi
removido e as imagens foram reduzidas para 360 px. `ambulancia-cima.png` é a mesma ambulância girada 90° para
apontar para cima, como os carros.
